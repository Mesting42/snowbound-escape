# 风帆雪橇张帆后正常着地误判修复

2026-10-25。用户反馈：没有空翻或已提前松手，雪橇基本对齐坡面、附近没有障碍，仍摔倒或失去雪橇。用户确认：张帆结束后平顺收帆下降，正常落地保留雪橇，真实撞障和危险空翻代价保留。

## 已复现的原因

无障碍、无空翻输入，直接调用正式物理。种子1、出发x=0、初始速度38m/s，离地2m发动张帆；约5.075s后落地主路。落地前角度约-0.027rad、坡度约-0.014，差不到1度，角速度约0.034rad/s，但技能已经结束、vy约-25.25m/s。原逻辑立即恢复18m/s²重力，并以统一冲击阈值>24判为摔倒。种子1的960/1000/1960/4640m及种子7的1400/3480/3520m也复现同类失败，包括上层着陆。

这是技能结束后的下降接续问题。没有扩大雪橇的碰撞权限，也没有绕过障碍检测。

## 修复规则

- `Player.sailDescent`独立于`ability`，仅在风帆主动技能于空中结束的边沿启动一次，最长4s。
- 前0.65s将下降重力从3.2m/s²平顺恢复到18m/s²；缓降期间按接近坡面限制相对法向下落速度为12m/s。限值始终向下，不提供新的抬升。
- 从上方靠近台面时使用上层坡度；处在台下时使用主路，不吸附到台面。台底、断桥与原着陆扫掠仍照常执行。
- 主动能力、速度上限、加速度、冷却都正常结束或继续计时，缓降不激活主动风流/增压特效，不增加碰撞保护。帆面保留小幅收帆姿态，随缓降结束恢复。
- 第一次接地、换乘、载具损毁、严重摔倒或极端地面保底恢复时清空。后续普通起跳不会重建缓降，计时到0不自动刷新；新的合法主动技能仍遵守原6秒冷却。
- 原`gradeLanding`不变：错误角度、过大旋转仍有摔倒/踉跄代价；实际岩石、冰柱、落冰照常使雪橇受损，牦牛乘客也仍只有既有一次护航。

`systems/sail-landing.ts`集中生命周期、重力过渡和坡面速度限幅，物理调用该模块；骑乘进入/退出统一清理字段。暂停不推进模拟，缓降计时及帆面均冻结。该字段不进入存档或检查点，不需要变更存档版本。
