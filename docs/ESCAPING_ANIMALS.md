# 动物随雪崩向前逃跑

2026-10-25。用户确认：三种动物持续向前奔跑/低飞，速度略慢于玩家，追近后自动接入；被雪崩追上的未接入动物退出场景。

## 当前行为

- 雪獭以20m/s沿雪道前进，两侧鳍肢交替划雪；牦牛以18.5m/s前进，四肢按对角交替奔跑。
- 雪鸮以21m/s沿地形低空飞行，左右翼镜像振动。模型自带2.15m飞行偏移，模拟只叠加不超过0.18m的起伏，避免高度重复计算。
- 以上速度低于双板28m/s正常巡航，起步或摔倒低速时动物可能拉开距离，恢复速度后可追上。
- 地面动物沿地形接触，从与主路相连的入口自动滑上高台；检测前方障碍起跳，台底接触和真实断桥仍受地形规则约束。动物不消费障碍，也不替玩家获取分数。
- 玩家追近当前实际位置时自动接入；沿用当前为双板或原伙伴剩余不足5秒、未摔倒、垂直距离接近的条件。机车、风帆继续在原地放置。
- 雪崩前沿追上动物时先将其退出，再执行本步接入判定；退出不会计为获得伙伴或提供奖励。已使用动物不会再次移动或重复接入。
- 开场、暂停、结算时位置与动作时间均冻结；继续游戏后恢复。超过玩家前方1200m生成范围的动物退出，防止停留或长局积累。

## 实现分工

`systems/escaping-animals.ts`负责无渲染依赖的动物真实位置、坡面/台底接触、障碍跳跃、雪崩退出；`Entity.escape`保存当前局的前一步位置、速度、竖向状态与动作时间。`Game.update`按固定1/120秒推进，暂停与结算由原有阶段控制统一拦截。

`systems/obstacles.ts`以双方相对位移进行扫掠，在交会时间比较高度，避免高速追越漏接；`used`在同帧写入，兼顾退场与奖励防重。检查点与重新开局重建实体，逃跑状态不写入旧存档，不需要迁移存档版本。

`render/world.ts`使用与玩家一致的固定步余量插值显示动物位置；`render/models.ts`只对已有模型添加肢体枢轴与动画，不修改玩家尺寸、相机缩放或碰撞规则。共享网格/材质和现有距离回收继续使用。
