# 紧凑乘客座舱与左上角雪崩警告

2026-10-25。用户确认：两种载具去掉过长后座，改为利用纵深错位的紧凑三席座舱，动物保持原有大小；左上角始终显示红色三角警告，远处小而静止，200/100/50m渐进放大、晃动。

## 乘坐造型

`render/passenger-models.ts`将牦牛放在后排、雪獭放在靠近镜头的前排，雪鸮位于上方栖杆。三种动物模型与人物比例均保持1，三席上车、换乘、被动加成和离队规则不变。平台由原来沿x方向拉长，改为在车体附近利用z方向容纳乘客，缩短前后轮廓。

正式几何精确包络：机车纵向4.65m，风帆雪橇4.35m，已计入雪板/滑橇；动物位置使用统一常量，拾取模型、图鉴与驾驶共用座舱。乘客与静态车体继续按材质合并并共享模板，满员独立模型的可见网格数保持机车36/风帆33个、三角形12120/11124，不新增每帧建模。

正式模型离线投影见[screenshots/passenger-models.png](screenshots/passenger-models.png)，数据见[passenger-models.json](passenger-models.json)。图中略去人物与纹理，仅用于检查比例、布局与几何遮挡，不是游戏实拍。

## 危险标志

`systems/avalanche-warning.ts`以真实雪崩距离计算状态，不改变雪崩速度或判负。`ui/avalanche-warning.ts`负责SVG与DOM同步，`ui/icons.ts`提供原创红色三角形与浅色感叹号，避免平台emoji变成黄色。

| 距离 | 行为 |
| --- | --- |
| ≥200m | 红色小标志常驻，静止 |
| 200m以内 | 按平滑曲线逐渐放大，轻微晃动 |
| ≤100m | 近险状态，放大和晃动更明显 |
| ≤50m | 达到上限：1.75倍、±9度、±1.25px位移、0.55s摆动周期 |

缩放和摆动使用两层transform，不互相覆盖；离开近险范围后用240ms过渡回到小尺寸。标志旁预留固定区域，桌面56px、矮横屏50px，最大动态包络仍在区域内，不因放大挤动数字。顶部路线条为左侧HUD保留最小间距；左下真实距离表保留。

正式模式开场/游玩显示；教学仅真实追逐步骤显示。暂停移除实玩HUD，停止动画，恢复后按当前距离重建；菜单和结算不显示。系统减少动态偏好关闭摆动、保留大小与红色提示。图标有包含真实距离的无障碍标签，不额外增加操作按钮，也不新增动画库或计时器。
