# 坡道自动接入与平台底部碰撞

2026-10-25。用户确认：与主雪道相连的坡道可直接滑上；从平台下方起跳应碰到台底、停止上升并回落，碰头本身不计摔倒。

## 原因与修改

原物理只实现平台顶面的向下着陆判定，没有平台底部的接触；人物可先从下方穿过薄台面，再回落着陆。接地时又一直沿既有route查询地形，主路到连接坡道没有接入逻辑，因此画面虽有连接，仍需跳跃才可能切到upper。

- `Terrain.crossesBranchEntry`只在与主路等高的前端入口允许接地接入，滑雪、动物与载具共用；平台中段下方没有自动接入权限。
- `systems/platform-contact.ts`按足点到头部的包络扫过本步移动路径，对应不同骑乘高度；上升时碰到台底会清理向上速度和未结算旋转，回落到原路线，不调用摔倒计数。
- 平台厚度`BRANCH_THICKNESS=0.45m`由物理和正式渲染共同引用，入口/末端也使用统一常量。
- 从上方落台保留原有姿态/冲击判断和奖励；断桥缺口不产生隐形天花板。末端汇合仍只结算一次分支。
- 教学与初次出发说明同步改成沿连接坡道直接滑上，避免再要求玩家额外起跳。能力、坡度、速度、雪崩和人物大小没有为了此次修复另行调整。

## 验证

构建/类型检查通过，41项测试全部通过，新增6项：

1. 5个种子×6种骑乘×3档速度的入口自动接入，无跳跃、无摔倒，接触高度连续。
2. 六种骑乘从平台中段下方起跳会停止上升，足点不穿到台面，无分支/空翻误结算、无额外摔倒。
3. 高速上升与旋转不能穿过台底，头部接触取消尚未落地的旋转。
4. 从上方下降仍正常落到上层并结算。
5. 真正断桥没有隐形台底，平台中段不存在自动吸附入口。
6. 4个种子×6种骑乘无需跳跃也能从入口滑入、在末端汇合，分支奖励只发一次。

正式规则模拟结果保存在`simulation-platform-contact.json`：18km冒险成功，用时629.6s；九项挑战全部成功（C1–C8三星，C9二星）；无尽总模拟3600s（含开场2.5s），前进111267m且仍运行。自动驾驶沿用原按键策略，未直接设置胜利。
