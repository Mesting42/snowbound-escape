# 障碍识别度调整

用户选择只修改造型与颜色，不增加动作文字、图标标签或悬浮提示。角色、镜头、输入与碰撞参数保持原有规则。

## 实体造型语言

| 情况 | 造型与配色 | 对应操作 |
| --- | --- | --- |
| 岩石、冰柱、落冰 | 深蓝灰硬质棱面，局部珊瑚色边缘；覆雪只占顶部小面积 | 跳过，不能依靠破障能力撞开 |
| 倒木、木栅栏、主路断木堆 | 暖色木材、清楚切面和裂口，横梁/碎板结构；倒木斜横展开 | 普通滑雪跳过；牦牛或机车可以撞开 |
| 当前能撞开的木障 | 木材本体保留暖色，局部护漆切换为明亮浅绿；失去对应骑乘后恢复珊瑚色 | 仅反映当前实际破障资格 |
| 低矮洞口 | 宽拱形入口、绿色内缘和横向檐口；支撑位于雪道后侧 | 保持贴地通过 |
| 上层真正断桥 | 完整留出6m缺口，断头上翘、露出木刺和珊瑚色端缘 | 跳过；任何载具都不能把缺口当作木障撞开 |

形体与材质也承担区分，不能只依赖玩家记颜色。正式游戏没有新增文字提示；对照图中的名称只属于开发验收图。

## 代码与规则一致性

- `src/render/obstacle-models.ts` 独立建立障碍造型，几何体全局复用，材质由世界注入；骑乘变化只更新局部材质引用。
- `src/systems/obstacle-rules.ts` 提供唯一的破障判断，碰撞和造型共同读取。主路log/fence/bridge只允许yak/bike破坏；上层bridge始终是实际缺口。
- `src/render/world.ts` 使用新模型；落冰只更新有明确标记的碎块，避免今后添加装饰时因子节点顺序导致整座设施漂移。
- 没有修改接触高度、判定距离、伙伴消耗、空翻、雪崩或分支生成规则。没有增加后处理、渲染通道、发光脉冲或每帧几何创建。

## 验证

生产构建和类型检查通过，26项测试通过。新增4项测试包括42组种类/骑乘的实际碰撞行为、木障颜色与破障规则同步、材质变更复用几何、洞口射线检测验证真实入口、腾空仍受原规则碰撞、断桥中央没有覆盖几何，以及落冰动画不移动支架。

`docs/screenshots/obstacle-models.png` 是直接投影实际模型几何的离线造型对照，各格独立取景；不是浏览器截图，不代表真实场景光照、贴图、视觉反应时间或GPU帧率验证。已完成一轮离线检查与一轮修正确认。受此前浏览器工具的页面访问限制影响，本轮未进行新的实际游戏画面与帧率复测，不能将历史60FPS以上结果外推到当前模型。
