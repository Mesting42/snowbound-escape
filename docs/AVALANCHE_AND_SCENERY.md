# 雪崩反馈与背景/障碍分离

日期：2026-10-25。用户确认：正式冒险/无尽中需要明确的雪崩反馈；背景装饰退后、淡化，真实障碍突出；不增加障碍文字标签。

## 发现与边界

源码中的冒险和无尽原本已有雪崩推进与追上判负。雪崩初始位于玩家身后240米，而镜头只显示附近几十米，因此真实雪浪长时间处于屏外。原来左下距离又是直接叠在雪地上的小字，远处危险反馈非常弱。

用户还报告距离表完全缺失和不会被追上。本轮没有现场浏览器诊断，不能将其唯一原因归结为教学隐藏状态或上述屏外问题。现已统一追逐/呈现开关，明确恢复正式模式的HUD显示，并用应用真实DOM和模拟验证关键生命周期，补足可重复的防回归保障。

背景混淆的明确来源：雪道两侧原先每120m有7组与石块障碍相似的近景装饰石，其中部分位于玩家前侧；冰川装饰还包含深色洞口；装饰植被、木屋会投下与近景物体相似的阴影。这些实际分布与材质已调整。

## 修改

- `systems/avalanche-feedback.ts`统一教学/正式模式的追逐开关及危险反馈，供游戏、HUD、渲染和声音读取。
- 正式冒险、无尽和挑战每次创建/更新HUD都会显式恢复雪崩距离的显示，清理旧隐藏属性；增加已有距离表内的“身后推进/正在逼近/雪浪临近”状态。仅雪崩距离表新增状态，不给障碍添加文字或标签。距离表有局部浅底，避免在雪面上消失。
- `render/avalanche-visual.ts`将真实雪浪与屏幕左侧的风卷雪雾分离。真实雪浪仅使用雪崩的路线x，体积向后展开，不把碰撞前沿钳在屏幕边缘。左侧18%范围的轻量雪雾是远处扬雪的环境反馈，远时仍有少量，逼近后增强。
- 方向光随危险程度最多减弱9%，新增低频轰鸣；音量遵循音效设置，暂停时关闭连续声音，视觉动画按模拟时间冻结。环境粒子关闭后仍保留必要的雪崩危险反馈。
- `render/scenery.ts`统一装饰深度和材质。树木/木屋z≤-24，岩台z≤-26，冰体z≤-32，设施z≤-30，均与玩家/障碍的z≈0分离；清除近景装饰石，远处只留3组低矮宽缓岩台。
- 背景材质按区域雾色淡化58%，移除近景木纹/裂口/凹凸，关闭对通行雪道的投影；不改变真实障碍共用材质和阴影。背景暗洞改为宽缓山脊，避免与真正可穿越洞口相似。
- 装饰按雪道网格远侧横截面的高度落地，避免退后后悬浮；上层可走平台、真断桥和终点避难站保持清楚的功能造型。

## 验证

`npm run build`通过。`npm test`共31项通过，新增5项覆盖：

1. 正式模式追逐启用、远处反馈存在、危险增强、菜单/胜利关闭；教学仅在指定步骤演示。
2. 使用linkedom渲染应用自身UI，验证教学隐藏→冒险/无尽、重试、暂停继续后的距离表与状态。它是DOM单元测试，不是页面访问或浏览器实玩。
3. 冒险与无尽真实推进、暂停冻结、测试制造持续低速后被雪崩追上判负；没有直接设置失败或移动雪崩伪造结果。
4. 真实雪浪的几何不超过局部前沿x=0，环境雪雾仅限左侧18%，暂停时间不改变动画。
5. 背景统一退后、材质淡化/复用、禁止投影且不污染源材质，放置高度与远侧雪面一致。

本轮未对之前被浏览器工具安全策略拒绝的本地页面再次尝试或绕过。没有新的实时WebGL、声音听感、截图或帧率验证；31项测试和构建不能替代实际视觉验收，历史90–165FPS也不能外推至当前构建。

运行依赖仍只有Three.js。linkedom仅作为开发测试依赖，不进入游戏构建。静态目录及ZIP同步更新，页面刷新后加载新版本。
