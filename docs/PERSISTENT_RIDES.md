# 动物与载具持续同行

2026-10-25。用户确认取消全部动物与载具的同行时限和时间显示；单独骑乘时，追近另一种动物自动换乘；三席乘客与主动技能持续时间/冷却保留。

## 当前规则

- 雪獭、牦牛、雪鸮、雪地机车、风帆雪橇都不再因时间或燃料耗尽自动离开。碰撞失去骑乘、严重摔倒、换乘和本局结束仍按各自规则处理。
- 单独骑动物时，追近不同动物立即换乘、原动物离队；同种不重复获取，不消费同种实体，不刷新能力、冷却或保护。动物接入仍受实际位置、垂直距离与摔倒状态限制。
- 车上追近动物仍走三席乘客逻辑，每种各一只；原动物随行上车，机车/风帆换乘保留已有乘客，载具损毁后清理乘客。牦牛的一次护航和其他被动保留。
- 主动技能仍有原来的2.8/3.8秒持续时间、6秒冷却；雪鸮/风帆只在主动能力生效期间减轻飞行重力，技能结束后正常下降，不会因持续同行而无限滑翔。雪鸮乘客的被动缓降仍独立生效。
- HUD保留伙伴/载具名称、技能名称、三席状态；删除同行秒数、进度条与到期预警。能力按钮继续显示主动技能冷却秒数。图鉴去掉同行时长与燃料限制，说明持续同行与换乘。

## 实现与交接

从`Player`删除`rideTime`，从`RIDES`删除`duration`，正式物理不再递减同行计时或执行到期/空中到期缓冲。没有用超大数或Infinity模拟“永不到期”，避免未来代码继续依赖过期状态。

`systems/obstacles.ts`只在不同种类时换乘；车辆接动物走已有`boardPassenger`，其余换乘走`enterRide`清理旧能力/冷却/增压。碰撞与严重摔倒仍走`leaveRide`统一清理乘客和能力，收益防重继续使用实体`used`。

挑战初始骑乘与教学固定雪鸮同步移除时限赋值；规则模拟诊断不再输出不存在的同行时间。检查点原本只保存安全位置、统计与种子，没有序列化整个Player，因此存档版本不变，恢复时仍从双板出发。

## 验证

类型检查与生产构建通过；`npm test`共79项通过，新增5项持续同行回归，并按新规则更新原到期与换乘测试：

1. 五种骑乘在无随机碰撞的测试地形上，以正式1/120s物理步持续120秒，超过旧时限仍在同行，三席保留，类型/配置没有旧计时字段。
2. 五种主动技能正常触发、结束、冷却中拒绝发动、冷却后再次发动，骑乘保持。
3. 三种动物所有同种/异种组合的自动换乘、旧能力清理、同种不刷新与防重。
4. 五种骑乘的正式HUD DOM没有同行秒数/进度条/到期提示，主动技能冷却和三席状态正确。
5. 五种图鉴说明没有旧时长、预警或燃料限制，保留技能冷却说明。
