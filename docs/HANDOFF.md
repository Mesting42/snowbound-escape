核心模拟不引用 Three.js、DOM 或 WebAudio。`Game.update` 产生事件，入口将事件分发到 UI 和音频；渲染读取游戏状态，不修改碰撞和分数。模拟可在 Node 环境独立运行，因此同一套规则同时用于实际游戏和测试。

## 坐标与时间

载具乘坐造型已改为纵深错排的紧凑座舱，布局位置在`PASSENGER_SEATS`，人物和动物不缩放。上方雪鸮栖杆与平台共同生成；座舱精确前后包络及红标距离/状态测试见[紧凑座舱与警告](COMPACT_CABIN_AND_WARNING.md)。警告显示层约每0.1s更新真实距离变量，CSS负责缩放与摆动，缩放/摆动节点分离；预留固定宽度避免挤动文字。暂停移除HUD，减少动态偏好停止摆动。

世界 x 以米为单位，沿雪道向右增长；y 向上，以米为单位；z 是美术纵深，不参与玩家前后操作。速度单位 m/s，HUD 转为 km/h；角度使用弧度；所有持续时间使用秒。

模拟固定步长 1/120 秒。渲染按显示刷新率更新；单帧最多处理约 6 个固定步，切后台不会通过追赶大时间差让雪崩瞬移。游戏暂停时 `Game.update` 直接返回，玩家、雪崩、技能、计时和机关状态都冻结。动物与载具没有同行倒计时或燃料时限。

人物和镜头使用前后物理姿态的只读插值，减少高刷新率下的位置阶跃，最多滞后一个固定步；物理、奖励和输入仍使用当前模拟状态。暂停和离散迁移不插值，角度按最短弧连接。相关模块不依赖Three.js，可独立测试。

## 连续坡面与高速接触

`Terrain.height(x)` 是视觉网格和物理共用的连续解析高度场。宽缓地形叠加种子相位、每 240 米模块中边界一阶导数为零的变化，以及有限范围的平滑跳台。`slope` 对同一高度场做中心差分。模块不是独立拼接高度，接缝不会制造台阶。

`makeTerrainGeometry`生成可见网格：主路积雪实体向下延伸256m以覆盖下方视野，上层平台只保留0.45m厚度并按真实桥缺口剔除。主路顶面与侧壁分离法线，侧壁UV按高度重复；这些下方面不参与碰撞。覆盖范围的射线测试见`tests/terrain-geometry.test.ts`。

地面速度受坡度、摩擦和骑乘巡航上限影响；接地时按坡面切线更新y与竖向速度，在与主路等高的连接坡道入口自动接入upper。空中按前后位置扫掠：从上方下降才落在平台顶面，从下方接触台底则中止上升并回落，不额外计摔倒。平台厚度由物理与渲染共用；中段不自动吸附，真缺口没有隐形底面。极端浮点边界保底恢复仍承担摔倒代价。

## 空翻、姿态辅助和奖励

`Player.angle` 保留连续值，`airRotation` 记录本次腾空的连续净旋转；不会在 2π 回绕时重复记分。松手后使用有最大角速度的阻尼弹簧回正，没有瞬间对齐。落地判断使用相对局部坡面角、相对冲击速度与旋转速度。

技巧奖励只在 `settleLanding` 中落地结算。严重失误取消本次空翻并打断连招；踉跄减少奖励；精准落地增加技巧与短时速度收益。一次结算后清零腾空累计角，避免二次发放。

## 雪崩与路线

玩家与雪崩共享同一个路线 x。上下分支只改变 y；换乘也不修改 x，因此真实危险距离不会因镜头、分支或模型切换而改变。雪崩按自己的连续速度推进，速度有上限；高水平滑行能够积累优势。

`systems/avalanche-feedback.ts`统一追逐与呈现开关；正式模式明确显示距离表，教学仅指定步骤启用。真实雪浪前沿不超过其路线x，左侧18%的雪雾独立表达屏外扬雪，不承担碰撞含义。危险程度同时控制少量光照变化和低频轰鸣，暂停使用冻结的模拟时间。新增背景装饰统一经过`placeScenery`，禁止重回玩家通行纵深或复制障碍的强对比材质，详见[调整记录](AVALANCHE_AND_SCENERY.md)。

上方路线可沿连接坡道直接滑入，也可从上方跳跃落入，在模块后段平缓汇合；从台底不能穿上去。木质支架、路牌和高处雪晶提供引导。主路始终可达，不以随机伙伴为必要条件。障碍间距为预设槽位，速度和跳跃参数受到上限约束。新增模块需要同时验证速度包络、台底接触、反应距离和落地后缓冲。

## 伙伴、载具与安全退出

五种主动技能已拆出`ABILITIES`，保持2.8/3.8s与6s冷却，分别调节真实提速、主动上限、阻力、滑翔重力和抬升。结束以最多12m/s²回到普通巡航，碰撞/换乘仍清理技能。`GameEvent.break`携带真实破木坐标与主动状态，经入口/UI送达World和Audio；碎木池4×12有界，低画质保留关键火焰/气流/雪带。动作和特效使用模拟时间，帆面形变权重不改共享几何。参数、接线与测试边界见[技能反馈记录](ABILITY_FEEDBACK.md)。

`Player.ride`表示当前驾驶/骑乘，`Player.passengers`独立保存最多三种动物乘客。`RIDES`统一声明跳跃、重量和巡航速度，没有同行时长；`Player.rideTime`已删除。动物/载具持续同行，单独骑动物时追近不同种类立即换乘，同种不消费实体或刷新技能。进入机车/风帆会携带当前动物，车辆间切换保留乘客。车上遇到动物走`boardPassenger`，不改冷却或能力。普通换乘与碰撞退出分别统一走`enterRide`/`leaveRide`，防止加成与增压残留。HUD保留名称、技能和三席，删除秒数、时间条与到期预警；主动技能持续时间和6秒冷却继续工作，详见[持续同行](PERSISTENT_RIDES.md)。

被动参数集中于`PASSENGER_EFFECTS`：雪獭让地面摩擦项乘0.8，雪鸮让下降阶段重力乘0.75；牦牛在原本会损毁载具的障碍撞击中消耗自己，保留载具和其他乘客。保护期、可直接撞开的木障碍和上层断桥不消耗牦牛。严重姿态摔倒不属于额外护盾范围。乘客不改变原载具质量/巡航上限，也不切换能力键。严重摔倒或载具损毁统一清理乘客；乘客状态不写入检查点，存档版本不变。

每次实际拾取载具后，`vehicle-companions.ts`按空位在玩家前方105/130/155m补充动物，位于实体呈现范围之外；附近已有同种或原动物已随车时跳过。新动物使用同一正式逃跑模拟，必须追上才能上车。来源实体`used`与派生ID防止重复刷出。`GameEvent.ride`明确发现对象，`sourceId`明确相遇来源，避免单步多次拾取时记录错对象。乘客上车计一次获得与100分，不把车上距离额外计入动物骑乘距离。

正式载具/图鉴/拾取模型共用后座造型，乘客拥有固定物种位置。车体、座椅与坐姿按材质合并；两种车体模板和三种坐姿模板共享网格，实例只改可见性与轻微起伏。野外动物与单独骑乘仍保留肢体动画。人物根比例不变。扩展规则与测试见[载具乘客记录](VEHICLE_PASSENGERS.md)。

未接入的三种动物由`escaping-animals.ts`在正式固定步内推进，速度独立配置为20/18.5/21m/s；车辆保持原位。`Entity.escape`只存当前局的速度、竖向状态、前一步位置与动作时间，不写入存档。地面动物跟随坡面、从连接入口进入高台，避障起跳时复用实体台底扫掠。`interact`同时扫掠玩家和动物的相对位移，并在相交时间插值高度，避免高速漏接；先退出雪崩吞没动物，再判定接入，统一使用`used`防重。渲染按同一固定步余量插值位置，骨骼按模拟时间运动，暂停即冻结。规则与验证见[动物逃跑记录](ESCAPING_ANIMALS.md)。

## 操作教学与预览

教学由六个真实目标驱动：起跳、落地结算空翻、精准落地、高速前进观察追逐、使用伙伴能力、完成高台路线。普通随机障碍与伙伴在教学中移除；能力与分支阶段固定提供雪鸮。未完成目标并前进超过 650m 时，只从当前模块安全起点重练，保留已完成步骤。镜头在这类离散迁移时立即校准，正常滑行仍使用阻尼跟随。

衣橱的试览与交易分别处理。未解锁服装可先查看真实三维结构，再点击独立按钮解锁；离开页面清理试览状态，恢复已装备外观。图鉴复用正式伙伴/载具模型。菜单近景保留开阔营地，避免植被投影覆盖文案。

牦牛和机车只撞开木质轻型障碍。受击可由伙伴挡下一次并退出。持续同行不会永久开启主动飞行：雪鸮技能结束恢复正常下降；风帆技能在空中结束时，`sailDescent`提供最长4s的单次收帆下降，前0.65s恢复重力并限制相对坡面的法向下降速度，接地/换乘/损毁清理。该阶段不延长加速或抬升、不增加免伤，也不修改`gradeLanding`的姿态代价；详见[风帆落地修复](SAIL_LANDING_FIX.md)。原先同行到期退出逻辑仍已删除。所有主路都有连续地面，退出不依赖跨越必死缺口。

## 存档、检查点与事务

命名空间 `snowbound.escape.save.v1`，版本 1。读取时验证主要数组、对象与奖励数值，损坏数据安全回到初始状态并提示。

安全检查点只在主路、接地、无摔倒且进入障碍前的安全模块起始段保存。恢复时重建 Terrain、普通双板角色和合理雪崩距离；不恢复旧输入、腾空角或短时能力。恢复位置之前的实体标记已消费，避免重复领取。

结算使用唯一 `runId` 去重，任务使用独立 `claimed` 集合。中途检查点不会提前发放本局收益；结算后才累计长期任务和钱包。任务再次点击无法重复发放。挑战星级只保存最高值。

## 性能与长期运行

树木在路段内按材质实例化；基础模型与大多数几何体共享；可见实体按距离创建和移除；后方路段回收其专属缓冲与材质。GPU 原点每 240 米重置，摄像机同步换算到新局部坐标，保留屏幕连续性。CPU 路线进度使用 JS double。

自适应模式每2秒评估渲染帧率，低于60时优先减少阴影/环境粒子，持续不足才降低像素比，最低保留1× CSS原生分辨率。普通屏幕也允许1.5×初始超采样；连续四个充足窗口才渐进恢复。流畅模式固定1×并关闭阴影；精细最高2×，大视口受额外采样预算限制。手机保持至少48米水平观察宽度，避免宽高比变化缩短预警时间。详见 [高速人物清晰度修复](CHARACTER_CLARITY.md)。

## 扩展入口

- 新挑战：向 `CHALLENGES` 添加目标、距离与三档阈值；已有统计可直接复用 `metric`，新指标需同时更新统计类型、结算与测试。
- 新伙伴 / 载具：扩展 `Ride`、`RIDES`、`makeRide` 与能力生命周期；必须定义安全退出，不能只加图标。会自主逃跑的动物还需扩展`Animal`与`ANIMAL_ESCAPE_SPEED`，定义路线、飞行高度/接触包络和肢体动画。
- 新外观：在 `OUTFITS` 与 `render/skier-appearance.ts` 增加独立造型，通过 `SkierRig` 的十个衣物挂点连接原骨架；共享模板、动画衣摆和存档规则见 [人物外观交接](OUTFIT_MODELS.md)。收费仅使用本地雪晶。
- 新障碍：同时增加类型、生成槽位、模型和扫掠碰撞规则。装饰物只能在雪道纵深外，不能伪装成碰撞实体。
- 障碍识别语义：修改 `render/obstacle-models.ts` 的实际形体与局部配色；破障资格统一由 `systems/obstacle-rules.ts` 提供，禁止美术和碰撞各写一套条件。新增木障同时补齐规则/材质一致性测试。
- 新长期任务：在 `MISSIONS` 声明统计字段、目标和奖励，领取防重由存档系统统一处理。
- 美术替换：可将程序模型替换为本地 glTF，但保持足点原点、正 x 朝向、米制比例和骑乘连接点。

## 旅行者模型与四套外观升级

2026-10-25：人物解耦为 ModelFactory、SkierRig 与服装几何；换装复用原 Skier 及骑乘实例。四套独立帽型、衣身和行囊已实现，原身材、购买记录、价格、动作与碰撞规则沿用。完整模块说明、216 个姿态组合及验证边界见 [OUTFIT_MODELS.md](OUTFIT_MODELS.md)。
