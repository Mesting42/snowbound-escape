# 雪地机车与风帆雪橇搭载动物

2026-10-25。用户确认：两种载具支持同时搭载多只动物，最多三只、每种各一只；乘客提供被动加成，能力键继续使用载具技能。原动物随行上车，换车保留乘客，载具损毁/到期后乘客离队。

## 玩法与参数

| 乘客 | 被动 | 结束方式 |
| --- | --- | --- |
| 雪獭·团团 | 地面滑行摩擦项减少20%，加快恢复和维持速度；巡航上限不变 | 载具退出时离队 |
| 冰原牦牛·岩角 | 抵挡一次原本会损毁载具的障碍碰撞，损失10%速度，获得1.2s保护 | 挡撞后牦牛离队，其他乘客和载具保留 |
| 雪鸮·云翎 | 下降阶段重力减少25%；上升、起跳高度不变，主动张帆时也只应用一次 | 载具退出时离队 |

重复物种不会再次接走，也不叠加加成。乘客上车不刷新燃料、主动能力、冷却或保护时间。动物仍需要在实际位置与玩家接近，遵守垂直距离和摔倒约束；高速追越按双方相对运动扫掠。每次真实上车消费实体并计100分与一次获得，重复检测不再奖励；车上距离仍记在载具名下，避免额外累加动物骑乘任务。

骑着动物遇到载具时可立即登车，原动物占据对应席位；切换机车/风帆保留已有乘客。骑动物时，原有“剩余不足5秒才自动换另一只动物”的规则仍保留。同类载具剩余时间充足时不自动替换。

载具到期、损毁或严重摔倒时统一回到双板，清空乘客与被动、主动能力、冷却及增压。空中到期仍保留既有最多4秒安全缓冲。牦牛保护仅用于障碍损毁，不替代严重空翻失误的落地规则；保护期碰撞、机车本可撞开的木材和上层真实桥缺口不消耗牦牛。

## 相遇与呈现

原动物间距在短时载具的相对速度下很难接满三席，因此拾取载具后为缺席物种安排一次前方相遇，位置分别距玩家105/130/155m，位于100m实体呈现范围之外。附近已有同种或已有该乘客时不再补充。动物正常奔跑/飞行，必须追近才能上车；来源实体的消费状态和派生ID防重，不从渲染循环生成。

两种载具都延伸后部乘坐平台；团团位于中部，岩角在后部，云翎收翼栖于前部横杆，并位于风帆可见侧。原人物与动物比例不变。HUD同时显示三个物种席位、占用状态与有效被动，原载具能力和时间继续显示；图鉴说明同步更新。

车体与静态坐姿按材质合并并缓存，源几何、UV、法线和根变换保留。相同载具和乘客实例共享合并网格。野外动物和单独骑乘的腿/翼动画不使用静态合并。
