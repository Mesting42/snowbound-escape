# 五种技能的实际效果与可见反馈

2026-10-25。用户确认同时加强技能实际效果与表现：机车喷火，风帆鼓帆/气流/雪尾迹，牦牛低头冲锋并在真实破木时发出碎木/撞击反馈；雪獭贴雪冲刺、雪鸮展翼滑翔。保留持续时间、6秒冷却、持续同行及只破木的规则。

表中为主动额外加速度，仍叠加原地面坡度/摩擦或空中基础加速度。速度有界，技能结束后以最多12m/s²回落至正常巡航上限，避免突然断速。能力与精准落地加速独立，持续同行不会永久开启技能或滑翔。

木质倒木、木栅栏、主路木堆仍只可由牦牛/机车破坏。牦牛技能不扩展到岩石、冰柱、落冰或上层真实缺口。普通破木仍保留97%速度，冲锋中的牦牛保留99.5%；计分仍为65，实体消费后不重复触发。

## 表现与性能

`data/abilities.ts`集中实际参数，`systems/abilities.ts`统一有效状态、速度上限与表现强度。强度按真实剩余时间在进入/离开各0.15s渐变，视觉不回写物理。

`render/ability-visual.ts`独立负责火焰、气流、雪带和碎木。关键火焰/气流/雪带在流畅画质、关闭粒子时仍可见；附加雪粉/尾气最多48点，减负时18点，关闭粒子为0。碎木固定4个短寿命槽位，每槽最多12个实例；低画质6个、关闭附加粒子仍保留4块以说明真实破坏，0.65s内回收。不会随长局不断新建网格。

`GameEvent.break`携带真实碰撞x/y、骑乘种类和主动状态，经正式Game→入口→UI→World/Audio链路投递。碎木转换到当前240m局部原点；短促震动遵守原镜头震动开关，声音遵守音效音量。核心技能效果不使用镜头缩放、全屏闪光或人物放大。

`render/ride-animation.ts`设绝对姿态，不累加角度；牦牛头部独立枢轴，雪鸮主动时后掠展翼，侧视轮廓可辨。帆面几何/鼓起位移与法线在`render/sail-geometry.ts`一次预生成，每个帆Mesh只修改自己的形变权重；共享几何不会污染图鉴/其他车辆。车体和座舱仍保持静态合并，帆面独立保留为一个可形变部件。

所有技能动作/附加粒子/碎木使用模拟时间，暂停冻结。结束隐藏技能表现，换乘、失去骑乘和新局清理旧状态；主动技能按钮在持续期间使用暖色发动状态，冷却秒数继续显示。引擎/风雪声音按真实技能增强，普通滑行恢复原状态。
