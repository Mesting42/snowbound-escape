# 雪道下方露出青色三角面的修复

2026-10-25。用户提供截图并确认：主雪道下方使用连续积雪山体延伸到屏幕底部，同时保留上层断桥的真实缺口。

## 原因

原雪道横截面只在前缘向下延伸5m。拉远镜头、较高视口或人物腾空时，短侧壁底部进入画面，露出后方远山网格，出现截图中的大片青色三角面。背景淡化并不能解决这个几何缺口。

## 实现

- 将正式地形网格生成抽到`src/render/terrain-geometry.ts`，不依赖WebGL，可直接做几何和投影测试。
- 主雪道积雪侧壁延伸256m，遮住常见视口下方的背景。每段120m仍保持960个三角形，没有用加密网格填满下方；为分离表面/侧壁法线仅多一列顶点。
- 雪道顶面高度与碰撞继续使用原Terrain解析函数，不改变人物大小、跳跃、坡面接触或前方观察距离。
- 主路前缘复制顶点，表面和侧壁分别计算法线；面朝向统一向外，防止深侧面影响雪面光照。
- 下方使用接近本区积雪的稳定颜色，UV按米制高度重复，避免大面积青色渐变三角形或把一条雪纹拉到屏幕底部。
- 上层平台保持原0.45m厚度和6m断桥剔除规则，不使用主山体的加深侧壁填掉可玩缺口。
- 相邻块使用世界坐标UV，局部原点变化不会改变接缝位置与纹理相位。

## 验证

构建与类型检查通过，35项测试通过。新增4项覆盖：侧壁深度、表面高度与法线、三角形数量、相邻路段及UV接缝、局部原点、断桥保持开放。

视野射线测试使用与游戏相同的正交相机方向和观察宽度：1440×900、844×390、1024×768、390×844，两个种子、三个区域位置、0/5m腾空高度及下方多个横向采样点，所有选定射线都命中连续山体，没有穿到远山。它验证几何覆盖，不是实时WebGL截图、纹理/光照或帧率复验，也不代表任意极端窗口比例或超出正常高度的穷举保证。
