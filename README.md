# 雪境疾行

原创、非像素风、侧视三维浏览器滑雪冒险。角色自动前进，以跳跃、后空翻、伙伴与载具能力穿越三个区域，逃离雪崩并抵达山脚避难站。

## 启动与构建

需要 Node.js 22.12 或更新版本。首次获取源码后，使用锁文件安装依赖。

```powershell
git clone https://github.com/Mesting42/snowbound-escape.git
cd snowbound-escape
npm ci
npm run dev -- --host 127.0.0.1 --port 6284 --strictPort
```

开发地址：<http://127.0.0.1:6284/>。本地生产预览可使用 <http://127.0.0.1:6285/>。

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 6285 --strictPort
npm test
npm run simulate
```

`dist/` 是完整静态网页产物，可部署到 Cloudflare Pages 等静态托管服务：构建命令 `npm run build`，输出目录 `dist`。不需要服务端、数据库或密钥。请通过 HTTP 服务访问，不能直接双击 HTML 加载 ES 模块。

根目录 `雪境疾行-static.zip` 是同一份静态产物的便携压缩包，解压后通过 HTTP 服务或静态托管打开。

移动设备同网段测试可在确认空闲端口后运行 `npm run dev -- --host 0.0.0.0 --port 6284 --strictPort`，再访问电脑的局域网 IP。不要复用其他游戏占用的服务或端口。

## 操作

| 操作            | 电脑                           | 横屏触屏       |
| --------------- | ------------------------------ | -------------- |
| 起跳            | 空格、上方向键或鼠标左键按下   | 点击雪道       |
| 后空翻          | 起跳后继续按住，或空中再次按住 | 空中按住雪道   |
| 准备落地        | 松开，提前留出回正时间         | 松手           |
| 伙伴 / 载具能力 | E                              | 右下角能力按钮 |
| 暂停            | Esc、右上角暂停                | 右上角暂停     |
| 摔倒恢复        | 按一次跳跃帮助起身             | 点击一次雪道   |

雪獭、牦牛会沿雪道向前逃跑，雪鸮会向前低飞，速度低于双板正常巡航。追近自动接入，单独骑乘时追上另一种动物就换乘，同种不重复接入；被雪崩追上的未接入动物退出场景。动物和载具持续同行，不会因时间或燃料耗尽离开，碰撞与换乘仍按规则处理。机车和风帆在沿途等待。空翻接近一圈时松手更容易稳住；一直按住落地会保留危险姿态。精准落地获得额外分数与短时速度收益。木栅栏和倒木可由牦牛或机车撞开，岩石和冰柱仍需跳跃避让。低矮洞口应贴地通过。

与主雪道相连的高台坡道可直接滑上，不必额外起跳；处在平台下方时起跳会碰到台底并回落，碰头本身不计摔倒。真正断桥仍需跳过，上层路线末端会自然汇合。

雪地机车与风帆雪橇均有三个动物席位，每种动物各一只。骑着动物登车会一起上车，驾驶中追近其他动物也会自动接上：团团减少滑行阻力，岩角挡下一次本会损毁载具的撞击后离队，云翎减缓下降。能力键仍使用载具技能；动物上车不刷新技能冷却，载具损毁后乘客全部离队，换车保留乘客。HUD不显示同行秒数或时间条，技能持续时间与6秒冷却保留。

按E/能力按钮可发动可见技能：机车喷火增压，风帆鼓起并带出气流，牦牛低头冲锋，雪獭贴雪冲刺，雪鸮展翼滑翔；各自实际提速/滑翔效果同步加强。冲锋破木会出现碎木、撞击声及可选短震动，岩石与冰障仍需避让。流畅画质或关闭粒子时保留关键技能造型，附加粒子减量。

风帆在空中收帆后会平顺转入下降，正常对齐坡面落地保留雪橇；下降缓冲最长4秒，接地即结束，不额外加速、抬升或提供碰撞免伤。实际撞障和危险姿态仍承担原有代价。

## 完整内容

- **雪山逃生**：18 公里，晨光松林 / 冰川峡谷 / 暮色雪原各 6 公里，目标约 8–12 分钟，终点为避难站。
- **无尽滑行**：有上限的追赶强度、受约束的雪道组合、种子变化、远段回收与局部坐标重置。
- **九项雪道挑战**：距离、空翻、连续精准落地、雪獭同行、载具收集、碰撞限制、高台路线、雪崩危险区计时及混合技巧。每关保存最高三星。
- **山间伙伴**：雪獭团团、冰原牦牛岩角、雪鸮云翎。
- **特殊载具**：雪地机车赤狐、风帆雪橇逐风，均有独立模型、手感、能力、持续时间与 HUD 状态。
- **旅途成长**：十二项可领取任务、四套不同结构的服装、三种双板外观、三维伙伴与载具图鉴。
- **声音与设置**：本地合成原创音乐及环境音效，音乐 / 音效独立音量，自适应 / 精细 / 流畅画质，震动、粒子、高光与姿态辅助开关。
- **存档**：记录、星级、任务领奖、外观、图鉴、设置、教程及冒险安全检查点。失焦和竖屏自动暂停。

## 素材与许可

所有角色、伙伴、载具、雪道、建筑、山体、图标和音频均由本项目原创代码生成，不使用现成完整游戏模板或运行时素材服务。中文字体为本地 Noto Sans SC 开源子集，许可位于 `public/fonts/OFL.txt`；开发时更新子集可运行 `node scripts/font.mjs`，正式游玩无需网络字体。Three.js 与构建依赖的许可见各依赖目录。详见 [素材说明](docs/ASSETS.md)。
